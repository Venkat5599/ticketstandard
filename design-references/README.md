# Design references

These websites were reviewed as design references for the event platform. Their layouts and interaction ideas are adapted to the product, without copying their source code or brand assets.

- [javii.tools](https://javii.tools/): small tools that edit a real output and export it. Applied as a working attendee QR pass style switch, with actual SVG generation.
- [QRLab](https://qrlab.javii.tools/): color and treatment controls for QR codes; its scan-while-editing premise informed the contrast-conscious QR preview controls.
- [Space Type Generator](https://spacetypegenerator.com/): kinetic type treatments. Applied as a restrained title reveal and ticket reveal, not perpetual or distorting display type.
- [GridType](https://www.grid-type.com/): generated geometric grids and parameterized letterforms. Applied as the underlying structure for the venue diagram and consistent table geometry.
- [Brik](https://brik.space/): a tool-building concept centered on controls and exports. Applied through the CSV export and map editing affordance; external tool APIs are not assumed.
- [Open Foundry](https://open-foundry.com/): a curated typeface catalogue. The selected Archivo and Archivo Black files are bundled locally through Fontsource for reliable loading.
- [Paper Shader](https://shader.paper.design/): attempted to inspect, but it was not reachable from the browser research tool during this build. No unverified shader effect was added to the operational dashboard.

The reference sites are inspiration, not connected services. Their components are not assumed to be licensed as reusable packages.
